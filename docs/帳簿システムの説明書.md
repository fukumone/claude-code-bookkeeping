# 帳簿システムの説明書（システム関係書類）

- 作成日: （YYYY-MM-DD）
- 対象: 仕訳帳・総勘定元帳（国税関係帳簿）と、青色申告決算書の数字
- 位置づけ: 電子帳簿保存法で「優良な電子帳簿」以外の電子帳簿（一般の電子帳簿）として保存するための
  システム関係書類。国税庁が備え付けを求める **①システム概要書 ②開発に際して作成した書類
  ③操作説明書 ④事務処理マニュアル** を、この1冊にまとめている
- `scripts/build_books.py` の仕様を変えたら、この説明書も同じコミットで直す
- 参照:
  - [国税庁 電子帳簿保存法一問一答【電子計算機を使用して作成する帳簿書類関係】](https://www.nta.go.jp/law/joho-zeikaishaku/sonota/jirei/07/index.htm)
  - [同 Ⅱ 適用要件【基本的事項】](https://www.nta.go.jp/law/joho-zeikaishaku/sonota/jirei/07/02.htm)

> サンプルの雛形。自分の運用に合わせて（）の部分と、使っていない入力の行を直す。

## 1. システム概要書

### 目的

個人事業の青色申告（複式簿記・65万円控除）で使う帳簿を、
証憑ファイルと台帳CSVから自動で作る。会計ソフトは使わない。

### 構成

| 要素 | 内容 |
|---|---|
| 実行環境 | python3。標準ライブラリだけを使い、外部の依存はない |
| プログラム | `scripts/build_books.py`（帳簿・決算書・転記シート・閲覧用HTML）<br>`scripts/rebuild_ledger.py`（管理台帳。証憑ファイル名の読み方を共有している）<br>`scripts/check_receipt_dates.py`（支払期限を過ぎたのに入金日がない売上の一覧。読むだけ）<br>`scripts/tax_rules.py`（所得税の速算表・復興特別所得税の率・みなし仕入率。転記シートとダッシュボードが共通で使う） |
| データの置き場所 | このリポジトリ。変更の履歴は git で残す |
| 閲覧 | `帳簿.html`（ブラウザで開く。外部に公開しない） |

### データの流れ

```
証憑  YYYY/MM/勘定科目/YYYYMMDD_取引先_金額.拡張子      ─┐
売上高・売上先一覧・定期経費・寄付金・確定申告サマリー ─┼→ build_books.py ─→ 仕訳帳・総勘定元帳・決算書・転記シート（CSV）
期首残高・手入力仕訳・入金日（CSV・手で作る）          ─┘                 └→ 帳簿.html（全年度）
```

### 帳簿の種類

| 帳簿 | ファイル | 中身 |
|---|---|---|
| 仕訳帳 | `YYYY/帳簿/仕訳帳_YYYY.csv` | 番号・日付・借方科目・借方金額・貸方科目・貸方金額・摘要・証憑 |
| 総勘定元帳 | `YYYY/帳簿/総勘定元帳_YYYY.csv` | 科目ごとに 前期繰越・日付・番号・相手科目・摘要・借方・貸方・残高 |
| 補助簿 | なし | 経費の明細は証憑のファイル名（日付・取引先・金額）が兼ねる |

## 2. 開発に際して作成した書類（仕様）

### 入力

| ファイル | 形式・内容 | 作り方 |
|---|---|---|
| `YYYY/MM/勘定科目/*.jpg 等` | `YYYYMMDD_取引先_金額.拡張子`。フォルダ名が勘定科目 | 仕分けskillで作る |
| `YYYY/売上高_YYYY.csv` | 月度・取引先ごとの売上（税込）。前年の12月度は期首の売掛金の消し込みに使う | 請求書から手で更新 |
| `YYYY/売上/取引先/*.pdf` | 請求書（`YYYYMMDD_請求書_金額.pdf`）。仕訳の証憑欄に使う | 保存のみ |
| `YYYY/売上先一覧_YYYY.csv` | 売上先の名前・所在地・法人番号・金額（決算書3面） | 手で更新 |
| `YYYY/定期経費_YYYY.csv`（任意） | `月,金額,借方,貸方,摘要`。領収書が届かない定期の経費（口座から引き落とされる掛金など）。借方に地代家賃・減価償却費・水道光熱費は書かない | 引落を確かめて手で更新 |
| `YYYY/寄付金/寄付金_YYYY.csv`（任意） | `No,寄付日,寄付先,金額,区分,受領証明書,ファイル名`（寄附金控除） | 手で更新 |
| `YYYY/確定申告サマリー_YYYY.csv` | 売上高・地代家賃（月額・支払先・事業按分率）・水道光熱費の事業按分率・固定資産・照合用の経費・社会保険料控除・小規模企業共済等掛金控除・医療費控除・専従者給与・扶養控除・基礎控除・青色申告特別控除・予定納税 | 手で更新 |
| `YYYY/帳簿/期首残高_YYYY.csv` | 前年の貸借対照表の期末の資産・負債。事業主貸・事業主借・元入金は書かない | 年1回、手で作る |
| `YYYY/帳簿/手入力仕訳_YYYY.csv`（任意） | 日付・借方・貸方・金額・摘要・証憑 | ほかのCSVにない取引だけ手で書く（前年分の消費税の納付など） |
| `YYYY/帳簿/入金日_YYYY.csv`（任意） | 月度（`YYYY/MM`）・取引先・入金日。取引先は売上高CSVの列名と同じ。前年12月度の入金もこの年のファイルに書く | 通帳を見て手で書く |

### 仕訳の作り方

| 取引 | 日付 | 借方 | 貸方 | 金額 |
|---|---|---|---|---|
| 経費 | 証憑の日付 | 勘定科目（フォルダ名） | 事業主借 | ファイル名の金額（税込） |
| 売上 | 月度の末日 | 売掛金 | 売上高 | 売上高CSV |
| 期首の預金の振替 | 1月1日 | 事業主貸 | 普通預金 | 期首残高の普通預金（入金先の口座を個人の口座として扱う場合） |
| 入金 | 入金日（なければ支払期限＝月度の翌月末で仮置き） | 事業主貸 | 売掛金 | 売上高CSV。入金日は入金日CSV |
| 期首の売掛金の入金 | 入金日（なければ1月末で仮置き） | 事業主貸 | 売掛金 | 前年の売上高CSVの12月度（期首残高の売掛金と一致しなければ中止） |
| 定期経費 | 月末 | CSVの借方 | CSVの貸方 | 定期経費CSV |
| 地代家賃 | 月末 | 地代家賃 | 事業主借 | サマリーの月額（総額） |
| 家事按分（期末） | 期間の末日 | 事業主貸 | 水道光熱費・地代家賃 | 総額 −（総額 × 事業按分率、1円未満四捨五入） |
| 減価償却（期末） | 期間の末日 | 減価償却費 | 工具器具備品 | サマリーの年額（定額法・直接法） |
| 手入力 | CSVのとおり | CSVのとおり | CSVのとおり | CSVのとおり |

- 売上の入金先の口座は、既定では個人の口座として扱う（`DEPOSIT_ACCOUNT` が事業主貸）。普通預金は帳簿で使わず、
  通帳との照合は「請求した分が入金されたか・いつか」だけにする。事業専用の口座で受けるなら、
  `DEPOSIT_ACCOUNT` を普通預金にし、その口座のすべての出入りを仕訳にして期末残高を通帳と合わせる
- 入金日が期間の末日より後（入金日CSVにない分は、支払期限が期間の末日より後）の売上は、売掛金のまま残る
- 経理方式は税込経理。納めた消費税は納めた年の租税公課（手入力仕訳）、還付は雑収入
- 期間は、指定がなければ売上を計上済みの最終月まで（確定申告サマリーと期間を揃えるため）
- 元入金は 期首の資産合計 − 負債合計 で計算する
- 消費税の計算に使う課税売上は「売上高」の勘定だけ。雑収入（消費税の還付など）は不課税として除き、
  決算書2面・3面には別の行で載せる。簡易課税だけに対応（みなし仕入率は `scripts/tax_rules.py`）

### 除外・中止のルール

- ファイル名に `重複`・`カード控え`・`_dup` を含む証憑は、同じ取引の別の証憑として除外する
- 金額の直後に通貨コードが付いた証憑（`_22USD` など）と `_USD22` の形は、円に換算していないものとして読まない
- 出力はすべてメモリ上で作って検算し、最後にまとめて書き出す。次のときは**何も書かずに中止する**:
  - 日付・金額を読めない証憑、または jpg/jpeg/png/pdf 以外の拡張子の証憑がある
  - 経費として知らない科目のフォルダ、または CSV から計上する科目（地代家賃・減価償却費・定期経費の借方の科目）のフォルダがある
  - 定期経費CSVの借方が、サマリーから計上する科目（地代家賃・減価償却費・水道光熱費）になっている
  - 期首残高に 事業主貸・事業主借・元入金、区分違いの科目、同じ科目の2回目がある
  - 期首の売掛金が前年12月度の売上と合わない
  - 期首残高の普通預金が負の値、または期首の振替以外の仕訳（定期経費CSV・手入力仕訳など）に普通預金がある
  - 入金日CSVの行が読めない、同じ月度・取引先が2回ある、売上のない月度・取引先がある、
    入金日が月度の末日より前（期首の売掛金は1月1日より前）
  - 期間の末日がまだ来ていない（未発生の取引を書かないため）
  - 専従者給与が0円でない（未対応）
  - 貸借が一致しない、または決算書の欄どうしの計算（経費の合計・差引金額・所得・貸借の合計）が合わない
  - 確定申告サマリーの所得控除の内訳の合計が、合計の行と合わない
  - 入力CSVの値が読めない（全年度の決算書CSVも読み直して検算する）
- 金額が0円の定期項目（家賃・定期経費・減価償却費）は仕訳を作らない
- 実行のたびに確定申告サマリーの売上・経費と照合し、結果を決算書CSVと `帳簿.html` に残す

### 出力

| ファイル | 内容 |
|---|---|
| `YYYY/帳簿/決算書_YYYY.csv` | 青色申告決算書（一般用）1面・4面の数字、サマリーとの照合結果、注記 |
| `YYYY/帳簿/転記シート_YYYY.csv` | 作成コーナーに入力する数字（決算書2〜4面・所得税・消費税）。所得税は税金の計算（課税される所得金額→税額→申告納税額→第3期分）まで入れ、期中は暫定値 |
| `帳簿.html` | 全年度の決算書・仕訳帳・総勘定元帳・入金状況・年次推移・転記シート |

### ソースコードと変更の記録

ソースコードは `scripts/build_books.py`。開発と変更の経緯は、このリポジトリの git 履歴（コミットメッセージ）に残る。

## 3. 操作説明書

### 帳簿を作る

```bash
python3 scripts/build_books.py 2026      # 売上を計上済みの最終月まで（期中）
python3 scripts/build_books.py 2026/12   # 年末に1年分で確定させる
```

実行すると、件数・売上・経費・所得と、サマリーとの照合結果が表示される。

### 見る・印刷する

- `帳簿.html` をブラウザで開く。上部で年を、タブで
  決算書／仕訳帳／総勘定元帳／入金状況／年次推移／転記シート を切り替える
- 入金状況は、売上（月度×取引先）ごとの入金日と状態（通帳で確認／仮置き／未入金）の一覧。
  仕訳帳の売上と入金を摘要で突き合わせて作り、未入金の合計が売掛金の期末残高と合わなければ中止する
- 仕訳帳は摘要・科目・月で絞り込める。証憑欄のリンクから画像・PDFを開ける
- 紙に出すときは、ブラウザの印刷機能で表示中のタブを印刷する（タブなどの操作部分は印刷されない）
- CSV は表計算ソフトでそのまま開ける

### 過年度

帳簿を作る前の年は、申告書の控えから転記した `決算書_YYYY.csv` だけを置く。
出典欄が「申告済み」で始まる年は、スクリプトが生成し直さない（`帳簿.html` の表示と、消費税の基準期間・前年の税額の計算にだけ使う）。

## 4. 事務処理マニュアル

### 毎月

1. 証憑を `images/` に置き、`/update-expenses`（または `/sorting-receipt-images`）で仕分ける
2. `python3 scripts/rebuild_ledger.py YYYY/MM` で管理台帳、`python3 scripts/build_books.py YYYY` で帳簿、
   `python3 scripts/build_dashboard.py` でダッシュボードを更新する
3. git でコミットする（1回の作業＝1コミット）

### 年末・申告のとき

1. 12月分までの証憑を仕分け、通帳を見て `入金日_YYYY.csv` に入金日を書いてから（未記入の分は `python3 scripts/check_receipt_dates.py` で一覧できる）、
   `python3 scripts/build_books.py YYYY/12` で1年分を確定させる（注記の「仮置き」が0件になっているか、`帳簿.html` の入金状況で見る）
2. 払込証明書・控除証明書と金額を照合する
3. 転記シートを見ながら確定申告書等作成コーナーで入力し、e-Tax で送信する
4. 確定した貸借対照表の期末の資産・負債から、翌年の `期首残高_YYYY.csv` を作る
   （事業主貸・事業主借・元入金・所得は書かない。元入金はスクリプトが計算する）

### 訂正・削除

- 帳簿のCSVは直接直さない。元の証憑・台帳・手入力仕訳を直してから生成し直す
- 証憑の削除・移動・リネームと金額の訂正は `訂正削除履歴.csv` に記録する（事務処理規程 第8条）
- 変更の前後は git の履歴で追える

### 保存

| 項目 | 内容 |
|---|---|
| 期間 | 7年（帳簿・決算関係書類） |
| 場所 | このリポジトリ。バックアップ先は（保存先を書く） |
| 見読可能装置 | （使うPC）とブラウザ。紙にはブラウザから印刷する |

### 税務調査のとき

- 帳簿データの提出（ダウンロード）を求められたら、`YYYY/帳簿/` の CSV をそのまま渡す
- 画面（`帳簿.html`）と印刷物でも示せる
