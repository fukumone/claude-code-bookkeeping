## 画像仕分けワークフロー

対象: `images/` 配下の未仕分け画像（引数があれば `images/$ARGUMENTS/`）

### ワークフロー

1. **対象フォルダ走査**
   - `images/` 直下（または `images/$ARGUMENTS/`）のJPG/PNG/PDFを一覧化
   - 既にリネーム済み（`YYYYMMDD_*_*.{ext}`に合致）のファイルは除外
   - 処理対象件数を報告

2. **各画像を読み取り**（Read tool で1件ずつ）
   - 抽出項目: 取引日、時刻、店舗/取引先、合計金額、品目、支払方法、伝票番号
   - 読取不可の場合は「読取不可」と明記してスキップせず報告

3. **分類提案**（CLAUDE.md の「勘定科目一覧」「勘定科目の判断基準」に従う）
   - 金額・店舗・品目から勘定科目を決定
   - 貸方は既定で「事業主借」、不明なら確認
   - **所得控除対象は事業経費と別扱い**（後述「所得控除の振り分け」参照）

4. **提案を一覧表示** — ユーザー確認用のバッチテーブル

5. **確認後に実行**
   - ファイル名: `YYYYMMDD_取引先_金額.拡張子`
   - 移動先: `YYYY/MM/勘定科目/`
   - 必要なら `mkdir -p` で親フォルダ作成

6. **管理台帳の更新案内**
   - 処理後、`summarizing-monthly-expenses` の実行を提案

### 提案フォーマット（厳守）

対象件数が複数ある場合は以下の一覧で提示:

```
## 仕分け提案（全XX件）

| # | 元ファイル | 日付 | 取引先 | 金額 | 科目 | 新ファイル名 | 移動先 |
|---|-----------|------|-------|------|------|-------------|-------|
| 1 | IMG_0001.pdf | 2026/10/03 | CAFE EXAMPLE | ¥720 | 会議費 | 20261003_CAFEEXAMPLE_720.pdf | 2026/10/会議費/ |
| 2 | IMG_0002.pdf | 2026/10/05 | SAMPLE SHOP | ¥2,200 | 消耗品費 | 20261005_SAMPLESHOP_2200.pdf | 2026/10/消耗品費/ |

## 要確認（読取不可・判断に迷う）
| # | ファイル | 問題 |
|---|---------|------|
| 3 | IMG_0003.jpg | 金額不鮮明 |

上記で実行してよいか確認してください。
```

1件のみの場合は CLAUDE.md の個別フォーマット（レシート内容／仕訳／ファイル名／移動先）で提示。

### ファイル名規則

```
YYYYMMDD_取引先_金額.拡張子
例: 20261003_CAFEEXAMPLE_720.pdf
```

- 取引先: スペースなし、半角英数推奨（カナ/漢字可）
- 金額: 税込、カンマなし
- 同名ファイルが既存なら `_b`, `_c` ... を付与（集計スクリプトが読める接尾辞）

### 所得控除の振り分け（事業経費と別系統）

医療費・社会保険料・寄付金は**事業経費ではなく所得控除**。SKIPせず、以下のフォルダへ振り分ける（CLAUDE.md「所得控除用書類の場合」参照）。

#### 医療費（医療費控除）

- 移動先: `YYYY/医療費/{患者名}/`
- 患者（本人・家族）ごとに分ける。レシートに患者名が印字されていない場合はユーザー確認
- ファイル名: `YYYYMMDD_医療機関_金額.拡張子`（取引先の英数化は不要、漢字そのまま）
- 台帳: `YYYY/医療費/医療費_YYYY.csv`
  - カラム: `No,診療日,患者,医療機関,金額,ファイル名`

#### 社会保険料（社会保険料控除）

- 移動先: `YYYY/社会保険料/{制度名}/`（例: 国民年金・国民健康保険）
- ファイル名: **`YYYYMMDD_制度名_金額_対象.拡張子`**（例: `20260430_国民年金_17000_3月分.jpg`）
  - `YYYYMMDD` = **納付日**（領収印の日付）。先頭の日付は必須。省略すると重複検知をすり抜ける
  - 対象 = 対象月・期。和暦は西暦に直す（令和Y年 → **Y + 2018年**）
  - 対象月が納付年と異なる場合のみ年を付ける（例: `_2025年11月分`）
- **配置は納付日の年フォルダ**。対象月が前年でも移動しない
  （社会保険料控除は納付した年の控除になる）

#### 寄付金（寄付金控除）

- ふるさと納税 → `YYYY/寄付金/ふるさと納税/`
- 台帳: `YYYY/寄付金/寄付金_YYYY.csv`（`No,寄付日,寄付先,金額,区分,受領証明書,ファイル名`）

#### 経費外（私用）

- 明らかに私的使用のもの（私用の衣類・食料品等）は `SKIP` 扱い → images/ に残置してユーザー判断

### 実行コマンド例

ユーザー確認後:
```bash
mkdir -p "2026/10/会議費"
mv "images/IMG_0001.pdf" "2026/10/会議費/20261003_CAFEEXAMPLE_720.pdf"
```

### 重複チェック

同月フォルダに **日付+時刻+金額+店舗+伝票番号** が一致するファイルが既存なら重複の可能性あり。
削除せずユーザーに確認し、重複なら `_重複` を付けて残す（CLAUDE.md「重複ファイルの扱い」）。

### 注意事項

- **元ファイルは削除せず `mv` で移動**（コピー後削除はしない、原子的に扱う）
- 年度違い（前年・次年の日付）を検出したら警告してスキップ
- 外貨表記は**取引月の月中平均レート（TTM）**で換算し、レートと出典を備考に記載する
  （CLAUDE.md「外貨建て経費の換算」参照。固定レートは使わない）
- **ファイル名を信じず画像の発行元を確認する。** 中身が名前と違う事故は実際に起きる
  （例: 社会保険料の領収書として保存したファイルの中身が、電気料金の領収書だった）
- 処理後は `summarizing-monthly-expenses YYYY/MM` を案内

### 完了後の出力

```
## 処理結果

- 移動: XX件
- スキップ（要確認）: Y件

次のステップ: 管理台帳を更新するなら `/summarizing-monthly-expenses 2026/10` を実行してください。
```
